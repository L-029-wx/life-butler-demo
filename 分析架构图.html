电子生活管家 · 总体架构 v3

L0–L7 九层链路 + 设备能力兼容层 + 双贯穿带 + 闭环验证 · 数据自下而上流动

链路要点

  • 九层：来源 → 生成 → 存储 → 加工 → 分析 → 判断建议 → 传达 → 验证
  • 数仓四层 ODS→DWD→DWS→ADS
  • 双贯穿：个性化引擎 + 家庭画像
  • 北极星 FLQI，指标 95+ 项

v3 新增的三个硬机制

  • 设备能力兼容层：按数据能力归类，换代不重做系统
  • 上下文归因：后门调整剥离气温/电价混杂
  • 成本模型：设备更换支出预测 + 到期集中度
  • 口径纪律：外部字段只进判断依据，不进分子分母

科学性与隐私

  • 模拟数据 + 参数标定（参数有真出处）
  • 生成器只产行为，不产标签（防循环论证）
  • 低敏路线：不采生物特征、不用摄像头
  • 隐私：公共屏不放个人建议；外部渠道只发结论
